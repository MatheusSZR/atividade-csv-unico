# Dados de teste

`destino_exemplo.csv` e `novas_exemplo.csv` sao fixtures pequenas para demonstracao e testes locais. Elas nao pretendem reproduzir todo o arquivo oficial.

Os identificadores usados como referencia para a atividade sao baseados na consulta publica de contratos do Compras.gov.br. A fonte oficial do conjunto e o Portal de Dados Abertos:

- https://dados.gov.br/dados/conjuntos-dados/compras_contratos
- https://compras.dados.gov.br/contratos/v1/contratos?cnpj_contratada=05513573000132

Para testar com o arquivo oficial, baixe um CSV do recurso de contratos, mantenha a coluna `Identificador` e execute o programa apontando para o arquivo de novas entradas e para o destino.
